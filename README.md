# 🍽️ Restaurant React

Site web de restaurant réalisé avec React.js et Vite.

## 📌 Présentation

Ce projet est un site web de restaurant permettant de présenter les différents menus, les spécialités et l'équipe du restaurant.

L'objectif de ce projet était de pratiquer React.js et de créer une interface claire et responsive.

## 🛠️ Technologies utilisées

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Git / GitHub

## ✨ Fonctionnalités

- Présentation des entrées, plats et desserts
- Présentation des spécialités
- Présentation de l'équipe
- Composants React réutilisables
- Utilisation des props
- Affichage dynamique avec `.map()`
- Design responsive
